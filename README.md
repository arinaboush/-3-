# Task Planner
## Описание
Task Planner — это расширение для Visual Studio Code, предназначенное для создания и управления списком задач.
Расширение позволяет добавлять задачи, отмечать их как выполненные, возвращать в список невыполненных и удалять.
## Возможности
- Добавление новых задач.
- Просмотр списка задач в боковой панели.
- Отметка задач как выполненных.
- Отмена выполнения задач.
- Удаление задач.
- Автоматическое сохранение списка задач.
## Используемые технологии
- TypeScript
- Visual Studio Code API
- Webview API
- Node.js
- npm
## Установка и запуск
###
Для работы с проектом необходимы:
- Visual Studio Code
- Node.js
- npm
### Установка
1. Клонировать репозиторий:
   ```bash
   git clone <repository-url>
   ```
2. Перейти в директорию проекта:
   ```bash
   cd planner
   ```
3. Установить зависимости:
   ```bash
   npm install
   ```
4. Скомпилировать проект:
   ```bash
   npm run compile
   ```
5. Открыть проект в Visual Studio Code и нажать `F5` для запуска расширения.
## Использование
1. Открыть боковую панель VS Code.
2. Найти раздел «Мой планер».
3. Открыть палитру команд с помощью `Cmd + Shift + P`.
4. Выбрать команду «Добавить задачу».
5. Ввести название задачи.
Для управления задачами доступны следующие действия:
- `✓` — отметить задачу как выполненную.
- `↶` — отменить выполнение задачи.
- `×` — удалить задачу.
## Хранение данных
Для сохранения задач используется `context.globalState` из Visual Studio Code API.
Каждая задача содержит два поля:
- `name` — название задачи (`string`).
- `completed` — статус выполнения (`boolean`).
Данные сохраняются между запусками редактора.
