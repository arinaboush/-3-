# Документация проекта «Планер задач»
## 1. Общая информация
**Название:** Планер задач (Task Planner).
**Среда разработки:** Visual Studio Code.
**Язык программирования:** TypeScript.
**Назначение:** управление пользовательскими задачами непосредственно в среде разработки.
## 2. Используемые технологии
- TypeScript — реализация основной логики расширения.
- VS Code API — взаимодействие расширения со средой разработки.
- Webview API — создание пользовательского интерфейса.
- HTML — структура интерфейса.
- CSS — оформление интерфейса.
- JavaScript — обработка действий пользователя в Webview.
## 3. Структура данных
Для хранения информации об одной задаче используется интерфейс `Task`:
```typescript
interface Task {
    name: string;
    completed: boolean;
}
```
Описание полей:
- `name` — название задачи.
- `completed` — логическое значение, определяющее, выполнена ли задача.
Для хранения списка задач используется массив объектов типа `Task`.
## 4. Хранение данных
Для сохранения списка задач используется механизм `context.globalState` из VS Code API.
Данные сохраняются в хранилище расширения и восстанавливаются при следующем запуске среды разработки.
## 5. Основные компоненты
### 1. Функция activate
Функция `activate` является точкой входа расширения.
При активации она регистрирует команды, создаёт представление в боковой панели и настраивает обработчики пользовательских действий.
### 2. Функция getTasks
Получает сохранённый список задач из `globalState`.
Также обрабатывает ранее сохранённые задачи старого формата, если они представлены строками.
### 3. Функция updateTasksView
Обновляет содержимое Webview, отображая актуальный список задач.
### 4. Функция escapeHtml
Преобразует специальные HTML-символы в безопасные текстовые представления перед добавлением названий задач в HTML-интерфейс.
### 5. Обработка сообщений Webview
Webview отправляет сообщения основной части расширения при выполнении действий пользователя.
В зависимости от полученного сообщения расширение изменяет список задач и обновляет интерфейс.
## 6. Функциональные возможности
1. Добавление задач.
2. Просмотр списка задач.
3. Удаление задач.
4. Отметка задач как выполненных.
5. Отмена отметки о выполнении.
6. Сохранение списка задач между запусками VS Code.
## 7. Взаимодействие компонентов
Пользователь взаимодействует с расширением через команды VS Code и боковую панель.
При изменении списка задач основная часть расширения обрабатывает действие, обновляет данные и сохраняет их в `globalState`.
После этого интерфейс Webview обновляется и отображает актуальное состояние списка.
## 8. Алгоритмы работы
### 1. Добавление задачи
1. Пользователь вызывает команду «Добавить задачу».
2. Расширение открывает поле ввода названия задачи.
3. После ввода названия создаётся новый объект `Task`.
4. Объект добавляется в массив задач.
5. Обновлённый список сохраняется в `globalState`.
6. Интерфейс обновляется и отображает новую задачу.
### 2. Удаление задачи
1. Пользователь выбирает задачу для удаления.
2. Расширение получает её индекс в массиве.
3. Метод `splice()` удаляет выбранный элемент.
4. Обновлённый массив сохраняется в `globalState`.
5. Интерфейс обновляется.
Удаление также доступно непосредственно в боковой панели через кнопку «×».
### 3. Изменение статуса задачи
1. Пользователь нажимает кнопку изменения статуса.
2. Webview отправляет сообщение основной части расширения.
3. Расширение получает индекс выбранной задачи.
4. Значение поля `completed` изменяется на противоположное.
5. Изменённый список сохраняется в `globalState`.
6. Интерфейс обновляется.
Также пользователь может отметить задачу выполненной через команду «Отметить задачу выполненной».
## 9. Взаимодействие с VS Code API
В процессе разработки использовались следующие возможности VS Code API.
### 1. ExtensionContext
Объект `ExtensionContext` предоставляет доступ к ресурсам и хранилищу расширения.
В проекте он используется для работы с `globalState` и регистрации объектов, которые необходимо освободить при завершении работы расширения.
### 2. Commands API
Для регистрации пользовательских команд используется метод `vscode.commands.registerCommand()`.
В расширении реализованы следующие команды:
- `planner.addTask` — добавление задачи.
- `planner.showTasks` — просмотр списка задач.
- `planner.deleteTask` — удаление задачи.
- `planner.completeTask` — отметка задачи как выполненной.
### 3. Webview API
Webview используется для отображения собственного HTML-интерфейса в боковой панели Visual Studio Code.
Для регистрации представления применяется метод `vscode.window.registerWebviewViewProvider()`.
### 4. Обмен сообщениями
Для взаимодействия Webview с основной частью расширения используется механизм сообщений.
Внутри Webview метод `vscode.postMessage()` отправляет информацию о действии пользователя.
В основной части расширения метод `onDidReceiveMessage()` принимает сообщение и выполняет соответствующее действие.
Перед изменением задачи дополнительно проверяется корректность её индекса.
### 5. GlobalState API
Для сохранения списка задач используется `context.globalState`.
Метод `get()` получает сохранённые данные, а метод `update()` записывает обновлённый список задач.
Благодаря этому информация о задачах сохраняется между запусками Visual Studio Code.
## 10. Заключение
В результате разработки было создано расширение «Планер задач» для Visual Studio Code.
Плагин позволяет добавлять, просматривать и удалять задачи, изменять их статус выполнения и сохранять список между запусками среды разработки.
При реализации были изучены механизмы расширения функциональности Visual Studio Code, работа с VS Code API, создание Webview и организация хранения данных.
